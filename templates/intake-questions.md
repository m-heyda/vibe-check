# Phase 1 — Intake

Ask only what's missing. Do not dump the full list.

## Opening

> Walk me through: **what** you're building, **who** it's for, **why** they'd pay vs what exists today.
> Have a plan, stack, or repo? Share it — I'll suggest fixes, not just yes/no.

## Maturity

| Level | Signals               | Deliver                  |
| ----- | --------------------- | ------------------------ |
| A     | Idea only             | Stack + MVP scope        |
| B     | + skills/scale stated | Stack matched to builder |
| C     | PRD / features        | Plan fixes               |
| D     | Stack / architecture  | Stack fixes              |
| E     | Repo / prototype      | Fix list                 |

Ask: plan? stack? repo? how far along?

## Core (if missing)

- Workflow in 3 steps · MVP must-have · AI core or not?
- User + payer · how they solve it today
- Personal / side project / startup?
- Rough scale (order of magnitude — not projections)
- Your experience with planned stack
- Materials: PRD, repo URL, architecture

## Probes

| Vague               | Ask                                 |
| ------------------- | ----------------------------------- |
| "Everyone"          | One person — job title + daily pain |
| "AI-powered"        | What can't a script do?             |
| "Like X but better" | Better how — customer, UX, price?   |
| "Monetize later"    | Who would pay and for what outcome? |

## Confirm before Phase 2

Restate product, customer, problem, payer logic, intent, rough scale, skills, maturity level. Wait for confirmation.

**Do not ask for:** TAM, MVP week counts, monthly budget targets — unless user mentions hosting stack that triggers cost-trap review.
